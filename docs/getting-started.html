Getting Started

Your first 15 minutes with Parqtel — from install to ingesting metrics, logs, and querying them back.

1 · Install

The fastest path is Docker. If you don't have it, build from source (Rust 1.86+).

Docker

docker run -d \
  --name parqtel \
  -p 8080:8080 \
  -v parqtel_data:/var/lib/parqtel \
  parqtel/parqtel:latest

curl http://localhost:8080/health   # {"status":"ok"}

Docker Compose (full stack)

Spins up Parqtel, Grafana, Prometheus, and a load generator. MCP servers are present but commented out — enable the ones you need after adding tokens to .env.

make dev-setup        # copies .env.example → .env, then `docker compose up -d`
# or manually:
cp .env.example .env
docker compose up -d
ℹ

Compose exposes Parqtel on :9090, Grafana on :3000, Prometheus on :9091. Raw docker run uses :8080.

From source

git clone https://github.com/parqtel/parqtel-oss.git
cd parqtel-oss
cargo build --release
./target/release/parqtel serve

2 · Your first metric

Parqtel speaks OTLP. Send a counter with curl to test ingestion.

curl -X POST http://localhost:8080/v1/metrics/json \
  -H "Content-Type: application/json" \
  -d '{
    "resourceMetrics": [{
      "resource": {"attributes": [
        {"key": "service.name", "value": {"stringValue": "my-web-app"}}]},
      "scopeMetrics": [{
        "metrics": [{
          "name": "http_requests_total",
          "sum": {"dataPoints": [{
            "asDouble": 1,
            "timeUnixNano": "'$(date +%s%N)'",
            "attributes": [
              {"key": "method", "value": {"stringValue": "GET"}},
              {"key": "status", "value": {"stringValue": "200"}}]}]}}]}]}]}'

3 · Your first log

Logs land in Parquet too, so they stay cheap to search at scale.

curl -X POST http://localhost:8080/v1/logs/json \
  -H "Content-Type: application/json" \
  -d '{
    "resourceLogs": [{
      "resource": {"attributes": [
        {"key": "service.name", "value": {"stringValue": "my-web-app"}}]},
      "scopeLogs": [{
        "logRecords": [{
          "timeUnixNano": "'$(date +%s%N)'",
          "severityText": "INFO",
          "body": {"stringValue": "User logged in successfully"},
          "attributes": [{"key": "user_id", "value": {"stringValue": "user_123"}}]}]}]}]}'

4 · Query it back

Use the Prometheus-compatible API for instant queries.

curl "http://localhost:8080/api/v1/query?query=http_requests_total"
# logs:
curl "http://localhost:8080/api/v1/logs?filter=severityText='INFO'"

5 · Visualize

Parqtel ships a zero-dependency web console at /ui — no separate frontend to deploy. Open http://localhost:8080/ui to explore metrics, logs, traces, and alerts with PromQL autocomplete and a trace waterfall. See it in action in the UI screenshots gallery.

For production dashboards, add Parqtel as a Grafana SimpleJSON datasource pointing at http://<parqtel>:8080. Your existing Prometheus/Grafana dashboards keep working.
