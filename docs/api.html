API Reference

Parqtel exposes a Prometheus-compatible HTTP API plus OTLP ingestion and Grafana SimpleJSON. The full contract is also served as OpenAPI 3.0 at /oas.

↗

Prefer an interactive view? Open the API Explorer — search and expand every operation straight from the OpenAPI spec.

Ingestion (OTLP)

All ingest endpoints accept protobuf or JSON (content-type negotiation). The /json variants accept OTLP/JSON.

MethodEndpointDescription
POST/v1/metricsIngest metrics (protobuf)
POST/v1/metrics/jsonIngest metrics (JSON)
POST/v1/logsIngest logs (protobuf)
POST/v1/logs/jsonIngest logs (JSON)
POST/v1/tracesIngest traces (protobuf)
POST/v1/traces/jsonIngest traces (JSON)
 
curl -X POST http://localhost:9090/v1/metrics/json \
  -H "Content-Type: application/json" \
  -d '{"resourceMetrics":[{"resource":{"attributes":[
    {"key":"service.name","value":{"stringValue":"demo"}}]},
    "scopeMetrics":[{"metrics":[{"name":"http_requests_total",
    "gauge":{"dataPoints":[{"asDouble":42,
    "timeUnixNano":"1700000000000000000",
    "attributes":[{"key":"method","value":{"stringValue":"GET"}}]}]}}]}]}]}'

Query (Prometheus-compatible)

MethodEndpointDescription
GET/api/v1/queryInstant query
GET/api/v1/query_rangeRange query
GET/api/v1/labelsList all label names
GET/api/v1/label/__name__/valuesList metric names
GET/api/v1/label/:name/valuesList values for a label
 
curl "http://localhost:9090/api/v1/query?query=http_requests_total"
curl "http://localhost:9090/api/v1/query_range?query=rate(http_requests_total[5m])&start=1700000000&end=1700003600&step=60s"

Logs

MethodEndpointDescription
GET/api/v1/logsQuery logs with filters
GET/v1/logs/countCount matching logs
GET/v1/logs/fieldsList available log fields
GET/v1/logs/field_valuesList values for a log field

Alerts

MethodEndpointDescription
GET/api/v1/alertsList all alerts
GET/api/v1/alerts/:idGet alert details
POST/api/v1/alerts/:id/acknowledgeAcknowledge an alert
POST/api/v1/alerts/:id/resolveResolve an alert
GET/api/v1/rulesList alert rules
POST/api/v1/rulesCreate an alert rule
PUT/api/v1/rules/:idUpdate a rule
DELETE/api/v1/rules/:idDelete a rule

Pipelines & Recording Rules

MethodEndpointDescription
GET/api/v1/recording_rulesList recording rule groups
POST/api/v1/recording_rulesCreate a recording rule group
DELETE/api/v1/recording_rules/:nameDelete a recording rule group
GET/api/v1/pipelinesList pipeline definitions
POST/api/v1/pipelinesCreate a pipeline
DELETE/api/v1/pipelines/:nameDelete a pipeline

Grafana SimpleJSON

MethodEndpointDescription

POST/tag-keysList tag keys
POST/tag-valuesList tag values
