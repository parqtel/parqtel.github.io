FAQ & Glossary

Common questions about Parqtel, plus the terms used throughout the docs.

What is Parqtel?

Parqtel is a single-binary, Rust-based observability backend. It ingests OpenTelemetry metrics, logs, and traces and stores them as compressed Apache Parquet, exposing a Prometheus-compatible query API, a Grafana SimpleJSON datasource, a built-in web UI, an alerting engine, and 7 AI-native MCP servers.

How does it compare to Prometheus / Loki / VictoriaMetrics?

DimensionParqtelTime-series TSDBs
StorageColumnar Parquet (10–20× compression)Custom TSDB (Prometheus) or LSM (VictoriaMetrics)
Footprint~15 MB distroless image, no external storeOften larger; may need sidecars/stateful sets
SignalsMetrics + logs + traces in one engineUsually separate systems (Prometheus + Loki)
QueryPromQL-compatible subsetFull PromQL
Best atCheap, long-lived, edge/archival telemetryLow-latency real-time alerting at scale
ℹ

Parqtel is complementary: point Grafana at it as a long-term, low-cost store while keeping your real-time stack.

Is it production ready?

The engine is built for production constraints: no unsafe code, clippy-denied panics, crash-safe Parquet writes, graceful shutdown, and a supply chain that is Trivy-scanned, cosign-signed, and OpenSSF Scorecard tracked. It is young software — validate against your retention, cardinality, and query patterns before relying on it for primary alerting.

Does it support tracing?

Yes — traces are ingested over OTLP (/v1/traces, protobuf or JSON) and viewable in the built-in /ui trace waterfall. Trace storage shares the same block model as metrics and logs.

How do I back up Parqtel?

Blocks are immutable once written, so they can be copied or snapshotted while the server runs. Back up index.bin for fast recovery; without it, the index rebuilds from the Parquet files on startup. See production notes.

What do I need for MCP?

Run the relevant parqtel-mcp-* binary with its API token (e.g. SLACK_BOT_TOKEN). Each server is independent and exposes /health. Point your LLM client's MCP configuration at the server's URL/port. See the MCP guide.

Glossary

TermMeaning
OTLPOpenTelemetry Protocol — the wire format for metrics, logs, and traces.
BlockA self-contained Parquet file for a fixed time window (2h metrics, 30m logs).
Row groupA horizontal slice of a Parquet block; carries min/max stats used for pruning.
CompactionMerging small blocks into larger ones (hourly) for fewer, fatter files.
RetentionTime-to-live per signal; expired blocks are evicted.
Memory bufferIndexed in-memory store making the most recent data queryable in ~1.7ms.
Recording ruleA precomputed PromQL expression materialized as a new series.
MCPModel Context Protocol — JSON-RPC standard letting LLMs call external tools.
SimpleJSONGrafana datasource plugin protocol Parqtel implements.
