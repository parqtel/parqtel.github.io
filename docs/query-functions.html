Query Functions

Parqtel serves a Prometheus-compatible query API at /api/v1/query (instant) and /api/v1/query_range (range). Examples below use localhost:9090.

Label matchers

Supported in every selector inside {}. The special label __name__ matches the metric name.

OperatorExampleMeaning
={method="GET"}Exact equality
!={status!="500"}Not equal
=~{host=~"api-.*"}Regex match (RE2)
!~{host!~"api-.*"}Regex not match

Range aggregations

Applied per time-step window; require a step on range queries. by/without grouping is supported.

FunctionExampleMeaning
avgavg(http_requests_total{method="GET"})Mean across window
sumsum(http_requests_total{} by (service))Sum, optional grouping
min / maxmax(memory_bytes{service="api"})Min/max across window
countcount(http_requests_total{status="500"})Number of points
stddev / stdvarstddev(response_time_ms{service="checkout"})Std deviation / variance

Range functions

FunctionExampleMeaning
raterate(http_requests_total{service="api"}[5m])Per-second increase of a counter (≥2 samples)
irateirate(http_requests_total{service="api"}[1m])Instantaneous rate (last two samples)
increaseincrease(http_requests_total{status="200"}[5m])Total increase (reset-safe)
deltadelta(temperature_celsius{sensor="room1"}[10m])Last − first (gauges; can be negative)
⚠

The range selector [5m] is parsed for Prometheus syntax compatibility, but the actual window is controlled by the query step.

Histogram function

FunctionExampleMeaning
histogram_quantilehistogram_quantile(0.95, http_request_duration_ms)φ-quantile from OTel cumulative histogram buckets (φ ∈ (0,1))

Instant transforms

Applied to the last value in the window; no step required.

FunctionExample
absabs(net_bytes_delta{interface="eth0"})
ceil / floorceil(cpu_fraction{host="web-01"})
roundround(latency_ms, 5) · round(cpu_fraction, 0.01)
clamp_min / clamp_maxclamp_min(cpu_usage{}, 0) · clamp_max(cpu_usage{}, 100)

Ranking functions

FunctionExampleMeaning
topktopk(5, http_requests_total{status="200"})Top N by last sample value
bottomkbottomk(3, cpu_usage{env="prod"})Bottom N by last sample value

Grouping clauses

by keeps only the listed labels; without drops the listed labels. Compatible with sum, avg, min, max, count, stddev, stdvar.

sum(http_requests_total{} by (service, status))
sum without (instance, pod) (http_requests_total)

label_replace

Applies a regex substitution from a source label into a destination label. $1, $2 refer to capture groups.

label_replace(cpu_usage, "short_host", "$1", "host", "([^.]+).*")

Constraints

Max samples per series5000 (dev) — query.max_samples_per_series
Quantile rangeopen interval (0.0, 1.0)
rate/irate/increase minimum≥ 2 samples in window
Step durationss, m, h, d

Not yet supported

  • Binary operators between two metrics (metric_a / metric_b)
  • predict_linear, deriv, idelta, absent, changes, resets
  • Time functions: time(), timestamp(), year(), month(), …
  • Subqueries (metric[5m:1m])
  • offset modifier (metric offset 5m)
  • label_join
